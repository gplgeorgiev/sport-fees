# Спорт Такси ⚽

Просто PWA (Progressive Web App) за събиране на месечни такси за детски спорт.
Самостоятелно приложение — един HTML файл, без бекенд. Данните се пазят локално в браузъра (localStorage).

**Живо:** https://gplgeorgiev.github.io/sport-fees/

## Функции
- **Начало** — събрано/очаквано за месеца, брой платили и длъжници, преглед по групи
- **Такси** — списък по групи и месеци, филтри и търсене, бързо отбелязване на плащане, частични плащания и история
- **Деца** — управление на деца (група, родител, телефон, индивидуална такса) и групи (месечна такса, цвят)
- **Справки** — приход по месеци, длъжници, последни плащания, експорт CSV
- Светла/тъмна тема, резервно копие (JSON) и възстановяване

## Използване
Отвори `index.html` в браузър, или го хостни на GitHub Pages / всеки статичен хостинг.
На телефон: отвори адреса → меню на браузъра → „Добави към началния екран“.

## Локално стартиране
```
python3 -m http.server 8000
# после отвори http://localhost:8000/
```
